FQA-6P Web App (Google Apps Script + Google Sheets)

ติดตั้ง
1. ไปที่ https://script.google.com/ สร้างโครงการใหม่
2. วาง Code.gs แทนเนื้อหาในไฟล์ รหัส.gs
3. กด + > HTML ตั้งชื่อ Index แล้ววางเนื้อหา Index.html (ไม่ต้องคัดลอกชื่อไฟล์ซ้ำ)
4. บันทึก เลือกฟังก์ชัน setup แล้วกด เรียกใช้ อนุญาตสิทธิ์; เปิดบันทึกการดำเนินการเพื่อรับลิงก์ Google Sheets
5. ใน Code.gs แก้ข้อความ CHANGE-THIS-TO-A-LONG-RANDOM-SECRET ภายใน setAdminKey ให้เป็นรหัสลับยาวเฉพาะของคุณ แล้วเลือก setAdminKey > เรียกใช้
6. กด ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท เว็บแอป
7. เลือก ดำเนินการในฐานะ: ฉัน / ผู้มีสิทธิ์เข้าถึง: เฉพาะบุคคลในองค์กร (แนะนำสำหรับงานวิจัยภายใน)
8. กด ทำให้ใช้งานได้ และคัดลอก URL เว็บแอปให้แต่ละหลักสูตร

คำเตือนสำคัญ:
- ต้นแบบวิจัยเท่านั้น: PIN หลักสูตรเป็นการควบคุมสิทธิ์ขั้นพื้นฐาน ไม่เหมาะกับข้อมูลอ่อนไหวหรือการใช้งานจริงขนาดใหญ่
- อย่าเปิดเว็บแอปให้ 'ทุกคน' ก่อนผ่านการทบทวนความปลอดภัยและ PDPA
- ควรใช้บัญชีมหาวิทยาลัยที่ควบคุมสิทธิ์ Google Workspace และจำกัดผู้มีสิทธิ์ดูชีต
- ไม่ควรบันทึกข้อมูลส่วนบุคคลของนักศึกษา/บุคลากรในช่องข้อความหรือหลักฐานสาธารณะ
- บัญชีหลักสูตรใหม่ลงทะเบียนเองได้: ก่อนใช้จริงควรเพิ่มขั้นตอนอนุมัติหลักสูตร/ยืนยันอีเมล
- ระบบนี้เก็บ URL หลักฐาน ไม่ได้อัปโหลดไฟล์เข้าระบบ และไม่ตรวจสิทธิ์การเข้าถึงของลิงก์
- คะแนน 6P เป็นแบบประเมินระดับองค์ประกอบเพื่อทดสอบต้นแบบ ไม่ใช่คะแนนรับรอง AUN-QA
- ต้องตรวจสอบความตรงของเครื่องมือและแนวทางคุ้มครองข้อมูลก่อนเก็บข้อมูลวิจัยจริง
